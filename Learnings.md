# Learnings

Use this file as a temporary intake queue for non-obvious findings discovered during implementation or investigation.

## Workflow

- Add new entries with a date, a task-oriented title, and enough context to judge when the finding applies.
- During documentation review, promote project-wide rules to `AGENTS.md` and circumstance-specific guidance to the appropriate page in [`docs/references/README.md`](docs/references/README.md).
- Remove an entry from this queue after its guidance has been promoted.
